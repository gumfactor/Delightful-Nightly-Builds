# Why This? — Neuro Arcade

> **Date:** 2026-10-04

## How This Idea Was Selected

**Selection method:** Fresh generation. Day 277 gives category index 6 (G, Game / Puzzle). Two pending G rows existed in the backlog (both stock-market quizzes). The lottery chance was 25% (no rated entries); the roll was 73, so the fresh path ran. Pool size: 2.

## The Decision

Candidates: (1) Neuro Arcade, playable experimental paradigms with real psychometrics; (2) a "prompt golf" game that needs a live API key to be meaningful; (3) a chess-endgame trainer. Neuro Arcade won because it uses real measurement, not mock data (millisecond RTs from the player's own device), and because no earlier build runs actual experimental tasks (Heuristic Hunt covers bias vignettes, TrialScope analyses RT data after the fact). The two backlog finance quizzes were skipped because finance is saturated in the catalog. This build measures behaviour instead of quizzing knowledge.

## Connection to User Context

The user teaches Stress and Coping, Social Affective Neuroscience, and AI Applications for Psychologists, and runs an affective neuroscience lab. Stroop, n-back, Go/No-Go, and the Ultimatum Game are standard in those areas. CSV export/import with a participant label lets a class pool data on phones and compare it to reference ranges.

## Why Tonight

The calibration note says low ratings come from builds without a real interface, mock data, or duplication of existing tools. This one is playable on a phone, generates real data, and has no off-the-shelf equivalent as a single offline file.
