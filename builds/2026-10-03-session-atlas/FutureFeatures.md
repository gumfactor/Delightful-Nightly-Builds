# Future Features

1. **Cross-link with git**: match session time ranges to commits on the recorded branch to show what each session produced (ties into the Cross-Agent Workstreams idea brief).
2. **Other agents**: parsers for Codex CLI and Copilot chat logs so all AI activity lands in one atlas.
3. **Pricing from model ids**: exact per-model prices (incl. long-context tiers) and a budget alert for weekly spend.
4. **Prompt quality review**: Claude-scored rubric on prompts (specificity, context given) correlated with tool errors and rework.
5. **Full-text search in HTML**: embed an on-demand search index (or serve via a tiny local server) to cover all prompts, not the first 40.
6. **Weekly digest routine**: scheduled Claude Code routine that runs the indexer and posts a short summary of time per project.
7. **Teamwork/Coda export**: push per-project hours into Teamwork time entries.
8. **Stale-work detector**: flag sessions ending on an unresolved tool error or an open question.
