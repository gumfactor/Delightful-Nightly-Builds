# Future Features — Noise Lab

1. **Microphone-matched levels:** measure a real room with the mic, then set masking noise a fixed number of dB below it. Needs a calibration step to be honest about SPL.
2. **Hearing-profile equalisation:** import audiogram thresholds and tilt the spectrum to compensate, so the notch and masking sit at equal sensation level.
3. **Fine-grained notch design:** several notches, and a notch width/depth sweep with logging so a tinnitus-matching session can be saved and compared over weeks.
4. **Kwyeter venue presets:** build spectra from measured venue recordings (third-octave data) instead of hand-made presets.
5. **Binaural beat and amplitude-modulated-noise modes** for research use, with the modulation rate shown against the quantised loop rate.
6. **Installable PWA** with offline caching and lock-screen media controls, so it keeps playing with the phone screen off.
7. **Spectrogram view** of a dropped-in WAV, compared against the synthesised target.
