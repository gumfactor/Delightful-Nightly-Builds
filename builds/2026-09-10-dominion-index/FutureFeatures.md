# Future Features — Dominion Index

1. **Persisted historical trend, not just one snapshot.** Store every successful fetch (not just the last one) in `localStorage` or `IndexedDB`, and render a real time-series line per industry/province instead of a single before/after delta badge.
2. **Industry × province cross-tab heatmap.** The raw data already has both dimensions; a heatmap grid (industry rows, province columns, color-scaled cell counts) would surface patterns a bar chart pair can't (e.g. "mining is concentrated almost entirely in Alberta and Saskatchewan").
3. **Per-industry drill-down list of actual company names.** Right now the SPARQL query only returns counts (by design, to keep the query fast and the client light). A secondary, on-demand query for a clicked industry/province cell — "show me the actual companies" — would connect the aggregate view back to real entities, useful for spotting specific Canada List gaps.
4. **Cross-reference against The Canada List's own database.** Highlight industries/provinces where Wikidata's company count is high but The Canada List's own catalog has few or no entries — turning this from a general-interest dashboard into an actual coverage-gap finder for the editorial team.
5. **A "confidence" indicator per company for the ownership heuristic.** Distinguish "no parent recorded, high confidence independent" from "no parent recorded, but this is a well-known subsidiary Wikidata just hasn't linked" using a secondary signal (e.g. cross-checking the company's Wikipedia infobox parent field, which is sometimes more complete than Wikidata's own statements).
6. **Scheduled refresh via a Claude Code Routine.** Since the query is fully deterministic and takes a few seconds, this could run nightly/weekly unattended and email or notify on any large swing in a specific industry/province total.
7. **AI-generated editorial blurb (Claude Haiku, runtime-only key).** Feed the top-line totals and week-over-week deltas to Claude and generate a short "what changed and why it might matter" paragraph for direct inclusion in Canada List editorial content — following the same aggregate-only, never-raw-data pattern other builds in this catalog use for their optional AI layers.
