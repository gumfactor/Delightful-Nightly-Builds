## Why Neurofact Wins

The user is a neuroscience professor who studies empathy, psychopathy, and stress. A game that challenges scientific literacy on exactly these topics is:
- Personally engaging at an expert level (the claims are detailed and technical)
- Professionally useful (can demo in Social Affective Neuroscience class)
- Novel (no tool in the user's stack does this)
- Solves the "Game must have a visual interface" requirement unambiguously
- Ships with complete, playable content even without the API key

The calibration note warns that every rated build scored 4/10 or below when it lacked a visual interface, used mock data, or duplicated existing tools. Neurofact has a full browser UI, 30 research-grounded questions, and no equivalent in the user's tool stack.
