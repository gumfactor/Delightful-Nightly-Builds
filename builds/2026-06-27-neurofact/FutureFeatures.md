# FutureFeatures — Neurofact

1. **Live arXiv question regeneration** — Wire the `src/generator.py` into a routine that runs weekly and updates `index.html` automatically with fresh questions sourced from the past 30 days of arXiv submissions in neuro/psych domains.

2. **Difficulty-gated progression mode** — Start players on Foundational questions only; unlock Advanced and Expert tiers as the player demonstrates accuracy above a threshold. Tracks mastery tier separately per category with localStorage persistence.

3. **Category drill mode** — Allow players to choose a specific category (Memory, Stress, Psychopathy, etc.) and play 10 questions from that category only — useful for targeted study before exams or grant writing.

4. **Classroom mode / presenter view** — A teacher mode where the question appears full-screen without the answer buttons, and the instructor reveals each button response click-by-click to use the game live in class as a discussion prompt.

5. **Explanation depth toggle** — Add a "Go Deeper" button that expands a longer explanation (2–3 paragraphs with citations) generated by Claude for each question — converts the game into a quick-study reference for literature.

6. **Session history and mastery tracking** — Store each game session's results (per-question right/wrong, category breakdown) in localStorage; surface a "You struggle most with [category]" report across sessions to guide further study.

7. **Custom question import** — Allow the user to paste a custom QUESTIONS JSON array and play against their own content — enables this to serve as a general scientific-claim literacy trainer beyond neuroscience.
