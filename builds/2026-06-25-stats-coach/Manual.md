# Manual — Stats Coach

## What it does
Stats Coach asks you five questions about your research design and returns:
- The correct statistical test for your situation
- A 3-paragraph plain-English explanation (generated by Claude Haiku) of why this test fits and what the results will tell you
- Runnable R and Python code ready to copy into your analysis
- An interpretation and reporting guide (APA-style format)

Responses for identical designs are cached in SQLite so repeat queries are instant.

## Requirements
- Python 3.11+
- `ANTHROPIC_API_KEY` set in your environment

## Install dependencies
```bash
pip install -r requirements.txt
```

## Run the server
```bash
cd builds/2026-06-25-stats-coach/src
python server.py
```

Then open [http://localhost:5000](http://localhost:5000) in any browser.

To use a different port:
```bash
PORT=8080 python server.py
```

## Using the interface
1. Select your **outcome variable type** (continuous, ordinal, or categorical)
2. Choose the **number of groups or conditions**
3. Toggle whether groups are **independent or paired/repeated**
4. Select your **normality assumption** (unknown → treated conservatively as violated)
5. Indicate whether you're testing **group differences** or an **association between two variables**
6. Optionally describe your study context — this personalises the AI explanation
7. Click **Get Test Recommendation**

Results appear below the form within ~5–10 seconds (or instantly if cached).

## Running the tests
```bash
cd builds/2026-06-25-stats-coach
python -m pytest tests/ -v
```

Expected output: 69 passed, 0 failed.

## Supported tests
The decision tree covers 15 statistical tests:
- Independent Samples t-test
- Paired Samples t-test
- One-Sample t-test
- One-Way ANOVA
- Repeated Measures ANOVA
- Mann-Whitney U Test
- Wilcoxon Signed-Rank Test
- Kruskal-Wallis Test
- Pearson Correlation
- Spearman Correlation
- Linear Regression
- Logistic Regression
- Chi-Square Test of Independence
- Fisher's Exact Test
- McNemar Test

## Cache
Identical design parameters hit the SQLite cache (`src/stats_coach.db`) and return instantly. The study context field is excluded from the cache key, so adding context to a cached design still returns the stored explanation.
