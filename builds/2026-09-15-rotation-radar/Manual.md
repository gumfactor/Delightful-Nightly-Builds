# Manual — Rotation Radar

A command-line tool that analyzes which S&P sector ETFs are gaining or losing relative strength against the broad market, and renders the result as an interactive Relative Rotation Graph (RRG)-style dashboard.

## Setup

```bash
cd builds/2026-09-15-rotation-radar
pip install -r requirements.txt
```

Requires internet access to Yahoo Finance at run time (the build/test environment does not need or use live network access — see BUILD_LOG.md).

## Running it

```bash
python main.py
```

This fetches ~9 months of daily closes for `SPY` and the 11 SPDR sector ETFs, computes each sector's RS-Ratio/RS-Momentum/quadrant, saves the snapshot to a local SQLite file (`rotation_radar.db`), and writes `rotation_radar.html` — open it directly in any browser.

### Useful flags

| Flag | Default | What it does |
|---|---|---|
| `--benchmark TICKER` | `SPY` | Benchmark to measure relative strength against |
| `--sectors T1 T2 ...` | the 11 SPDR sector ETFs | Override the ticker universe |
| `--period 9mo` | `9mo` | yfinance lookback window (any valid yfinance period string) |
| `--ratio-window N` | `10` | Trading days used to smooth the relative-strength line |
| `--momentum-window N` | `10` | Trading days used to compute the momentum rate of change |
| `--tail-length N` | `10` | Number of trailing points plotted per sector on the quadrant chart |
| `--no-ai` | off | Skip the AI commentary panel even if `ANTHROPIC_API_KEY` is set |
| `--output PATH` | `rotation_radar.html` | Output HTML file path |
| `--db-path PATH` | `rotation_radar.db` | SQLite history database path |

### Optional AI commentary

Set `ANTHROPIC_API_KEY` in your environment before running to get a short plain-English summary of the current rotation regime, generated by Claude Haiku strictly from the computed numbers. Without a key (or with `--no-ai`), the dashboard shows an equally complete deterministic summary built from the same data — nothing about the tool's usefulness depends on having a key.

```bash
export ANTHROPIC_API_KEY=sk-...
python main.py
```

## Reading the dashboard

- **Quadrant chart**: each sector's last 10 trading days plotted as RS-Ratio (x-axis) vs. RS-Momentum (y-axis), both centered at 100. The square marker is the latest point.
  - **Leading** (top-right): strong and still gaining
  - **Weakening** (bottom-right): strong but losing momentum
  - **Lagging** (bottom-left): weak and still losing
  - **Improving** (top-left): weak but gaining momentum — often the earliest actionable signal
- **Sectors table**: click any column header to sort. A small badge appears next to a sector's quadrant if it changed since your last run.
- **Commentary**: a plain-English read of the current regime (AI-written or deterministic — see above).
- **Export full history as CSV**: downloads every saved run's per-sector data, useful for your own charting or record-keeping.

Run the tool again on a later day (same `--db-path`) to build up rotation history — the "since last run" badges and CSV export both get more useful the more often you run it.

## Sample output

`sample_output/rotation_radar_demo.html` (and its matching CSV) is a rendered example built from synthetic data, since this build container has no route to Yahoo Finance. Open it directly to see the full dashboard layout before running the tool against your own live data.

## A note on the methodology

The exact RS-Ratio/RS-Momentum formula used by commercial RRG tools (StockCharts, Bloomberg) is proprietary and not publicly documented. Rotation Radar implements a standard, published cross-sectional-z-score approximation instead (documented in full in `PRD.md`) — it is internally consistent and produces the same Leading/Weakening/Lagging/Improving structure, but its exact numeric values will not match a commercial RRG tool one-for-one.
