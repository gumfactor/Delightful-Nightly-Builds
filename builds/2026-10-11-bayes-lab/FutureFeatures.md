# Future Features — Bayes Lab

1. **Two-group comparison lesson**: Bayesian t-test / mean difference with a ROPE and Bayes factor, using pasted CSV columns from SPSS or Qualtrics exports.
2. **Prior elicitation tool**: drag quantiles ("I'm 90% sure the effect is between 0.1 and 0.5") and fit the matching Beta/Normal prior, then carry it into any lesson.
3. **Shareable state**: encode lesson inputs in the URL hash so a configured scenario can be sent to a student or opened on a phone.
4. **Sequential testing lesson**: simulate optional stopping and show how p-values and Bayes factors behave when data are peeked at repeatedly.
5. **Calibration over time**: a larger rotating question bank with a reliability diagram (stated confidence vs hit rate) built from the stored history.
6. **Instructor mode**: print-friendly worksheets generated from each lesson's current settings, with answer keys.
7. **Optional AI tutor**: when the user supplies their own key at runtime, explain a student's chosen settings in plain language (kept opt-in because it sends data out).
