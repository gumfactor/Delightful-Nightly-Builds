Portfolio Lab never fabricates market numbers. Run the fetch script once to pull real historical prices, then reload this page.

  1. Install the one dependency (needs internet access): 
    pip install -r requirements.txt
  2. Fetch real data for the 12-asset teaching basket: 
    python fetch_data.py
  3. Reload this page — data.js will now contain real prices.

This step needs to run somewhere with real internet access to Yahoo Finance — not required for browsing this file directly once data.js is populated.
